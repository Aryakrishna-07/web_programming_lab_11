# User Validation Web App
Node.js + Express + SQLite. Credentials are checked against the `users` table (passwords hashed with bcrypt).

Run locally:  npm install && npm start  -> http://localhost:3000
Demo users:   elia / pretty123 | admin / admin@123 | student / lab2026
Deploy (Render): New Web Service -> connect repo -> Build: `npm install` -> Start: `npm start`
